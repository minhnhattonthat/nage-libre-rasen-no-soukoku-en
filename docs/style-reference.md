# Style reference

From the pilot (b001: MAP86, MAP85, MAP01, MAP01R), checked in-game. Match these voices.

## Voices
| Who | JP traits | English |
|---|---|---|
| Ann | leader, blunt, 私, よ/ね | upbeat, direct: "Hey, let's all go look for the Nage Statue together!" |
| Itsuki | casual, lazy, boy-crazy, 私, ～よーっ | whiny/sassy teen: "Ehh~. I don't wanna do something that boring~." |
| Makoto | childish, third person (真も…) | "Makoto's going too~!", "Makoto loves sleeping~!" Never "I" where JP says 真 |
| Shinobu | tomboy, オレ, ぜ/だな/ちまう | rough, short: "Tch, how could I let this happen...", "You've got guts." |
| Mio | polite ojou, ですわ, ましょう | prim, formal, no contractions: "How vexing, to lose in a place like this." |
| Old townsfolk | 〜だよ, お行き | warm, folksy: "Now, off to the pharmacist with you." |
| Monsters | ぶひ/きー + （meaning） | "Oink oink! (Not a chance!)", "Kee-kee-kee." Keep the noise, then the meaning in () |
| System/narration | 手に入れた, ～できます | "Got the "Baby Tee".", "Received some medicine." Plain, short |

## Example pairs
- 真%h（まこと）　%zも行くー。 -> Makoto's going too~!
- これで司%h（つかさ）　%zクンのハートは私のモノよーっ！！ -> With this, Tsukasa-kun's heart will be miiine!!
- おまえ・・・・・・ダイジョブか？ -> You... ...are you okay?
- ぶひっぶひっ。（食えねーモンならいらねーぞっ。） -> Oink! Oink! (I don't want it if I can't eat it!)
- ”チビＴ”を手に入れた -> Got the "Baby Tee".
- クリアー条件 / %c02　敵を倒して神社に行け -> Clear Condition\n%c02Defeat the enemies and go to the shrine
- お疲れさまでした。リセットボタンを押して下さい -> Thank you for playing. Please press the Reset button.
- One line split over two boxes: "Thanks to that, all the ladies and old guys on the shopping street" / "are at
  their wits' end." Make the pieces read as one sentence; no comma where the English sentence wouldn't have one.

  "We WILL get it back. For our dear student council president." (keeps the emphasis and the サマ irony).
